GET vs POST Methods

Demonstrating how HTML form methods differ in data visibility and URL behaviour

GET

GET Method

Form data is appended to the URL as query parameters.
Example: ?name=John&email=john@mail.com

POST

POST Method

Form data is sent in the request body, NOT visible in the URL.
Suitable for sensitive data like passwords and personal info.

Key Differences

Feature GET POST
Data Location URL query string Request body
Visibility Visible in browser bar Hidden from URL
Bookmarkable ✅ Yes ❌ No
Data Limit ~2048 characters No practical limit
Use Case Search, filtering Login, registration
Security Less secure More secure
