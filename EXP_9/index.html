Observing Internet Protocols

Using Browser Developer Tools Network Tab

Network Tab Observation Metrics

Press F12 or right-click and select Inspect, then navigate to the Network tab. Observe the following parameters:

URL & Protocol

The destination address and the version of transfer protocol used (e.g., h2 for HTTP/2, h3 for HTTP/3, or http/1.1).

Request Method

The action performed on the resource (e.g., GET to retrieve data, POST to submit data, etc.).

Status Code

The server's response indicator (e.g., 200 OK for success, 404 Not Found for missing resources).

Type & Size

The MIME type of the file (document, stylesheet, script, fetch, png) and the size of bytes transferred over the network.
