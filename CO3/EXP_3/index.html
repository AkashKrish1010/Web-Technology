💡 Intrinsic vs Modern Event Handling

  • Intrinsic (Inline HTML): Defined in markup (e.g. onclick="fn()"). Mixes structure and logic, limited to one handler per event.
  • Modern (addEventListener): Cleanly separates JS logic, supports multiple listeners, event capture/bubble phases, and dynamic removal (removeEventListener).
