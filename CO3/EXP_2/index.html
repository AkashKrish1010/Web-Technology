How It Works

This application demonstrates client-side result computation using JavaScript — simulating a Java Servlet workflow.

  1. Input Collection

    Student name, register number and three subject marks are read from the form using getElementById().

  2. Validation

    Checks for missing fields and ensures marks are within the valid range of 0 to 100.

  3. Computation

    Calculates Total, Average, Highest Mark, and Pass / Fail status dynamically.

  4. Dynamic Output

    Result card is rendered into the DOM using textContent and style — equivalent to PrintWriter in a Java Servlet.
